- Browser session, production credentials, raw JWT, cookies, refresh tokens, passwords, .env values, production PII, payment secrets и Telegram initData не собирались и не сохранялись.

Наблюдение:
- Серьёзность: P2.
- Тип: sensitive token exposure / httpOnly-cookie posture regression.
- Web auth login использует cookie-only body contract, но web refresh всё ещё возвращает JS-readable token fields.

Окружение:
- Local CYBA-606 workspace.
- Role/state: authenticated web admin/partner/customer session with httpOnly auth cookies.

Точные шаги воспроизведения:
1. Authenticate through POST /api/v1/auth/login on a web realm.
2. Убедиться, что response body не содержит access_token и refresh_token, а auth cookies выставлены.
3. С теми же cookies вызвать POST /api/v1/auth/refresh с empty JSON body.
4. Проверить JSON response body.

Ожидаемый результат:
- Web cookie refresh не должен отдавать raw access_token или refresh_token в JSON.
- Token-bearing refresh должен оставаться на /api/v1/mobile/auth/refresh или другом явно non-web contract.

Фактический результат:
- backend/src/presentation/api/v1/auth/routes.py выставляет auth cookies, затем возвращает TokenResponse with access_token and refresh_token.
- frontend/admin/partner authApi.refresh() отдаёт этот body browser JavaScript.
